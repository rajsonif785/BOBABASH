# The Day Earth Disappeared

An interactive scrollytelling experience exploring a fictional scenario in which Earth suddenly disappears.

## About the Project

**The Day Earth Disappeared** is a creative web experiment built around a simple but unsettling question: *What if Earth suddenly vanished without any explanation?*

The website tells this story through a sequence of scroll-driven scenes, taking visitors from an ordinary morning to a mysterious planetary disappearance and, finally, to a reflection on humanity's place in the universe.

The experience combines conversational storytelling, playful visual elements, and a scrapbook-inspired aesthetic to make an otherwise serious concept engaging and approachable.

## Features

- **Scrollytelling:** The narrative unfolds as visitors scroll through different scenes.
- **Interactive visuals:** CSS-based illustrations and animations help communicate the story.
- **Dynamic effects:** A progress indicator and scroll-triggered transitions provide visual feedback.
- **Distinctive design:** Handwritten annotations, playful typography, and imperfect layouts create a personal, experimental feel.
- **Responsive layout:** The website adapts to smaller screens.
- **Lightweight implementation:** Built using standard web technologies without a JavaScript framework.

## Technologies Used

- HTML5 for content and structure
- CSS3 for styling, layouts, and animations
- Vanilla JavaScript for scroll interactions and dynamic behavior

## Getting Started

No installation or build process is required.

1. Clone or download this repository.
2. Ensure the following files are in the same directory:

   ```text
   .
   ├── index.html
   ├── style.css
   ├── script.js
   └── README.md
   ```

3. Open `index.html` in a modern web browser.
4. Scroll through the page to experience the complete narrative.

**Note:** An internet connection is required to load the externally hosted Google Fonts. The core website does not require a backend or package installation.

## Purpose and Learning

This project was created to explore scrollytelling as a form of digital storytelling. It experiments with using scrolling, animation, typography, and visual transitions to guide visitors through a narrative.

It also serves as an opportunity to practise front-end development, experiment with visual design, and explore how a simple idea can become an interactive web experience.

## Project Status

This is an experimental creative project. Its design, animations, and storytelling can be refined further as development continues.
